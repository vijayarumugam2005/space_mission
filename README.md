# Space Mission Project

## Overview
This is a Power BI analytics project focused on space mission data and analysis. The project provides interactive visualizations and insights into space mission information.

## Project Details
- **Project Type**: Power BI Dashboard
- **File**: project power BI.pbix
- **Purpose**: Data analysis and visualization of space mission metrics and trends

## Files Included
- `project power BI.pbix` - Main Power BI workbook containing all dashboards, reports, and data models

## Features
- Interactive dashboards and reports
- Data visualizations and analytics
- Real-time insights into space mission data

## Requirements
- Microsoft Power BI Desktop (latest version recommended)
- Power BI Account or Power BI Pro License for sharing/publishing

## Getting Started

### Opening the Project
1. Download or clone this repository
2. Open Microsoft Power BI Desktop
3. Open the `project power BI.pbix` file
4. Explore the dashboards and reports

### Viewing Online
If published to Power BI Service:
1. Navigate to your Power BI workspace
2. Open the published report
3. Interact with the dashboards and apply filters as needed

## Usage
- Use the interactive filters and slicers to explore different views of the data
- Hover over visualizations for detailed information
- Export reports or screenshots as needed for presentations or documentation
